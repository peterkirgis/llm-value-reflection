# The Continual Constitutional Convention

What happens when language models are asked to revise the documents that govern them? This repoistory holds code and results for an experiment which has LLMs iteratively edit their own model specs, constitutions, and system prompts, and then codes these edits on two questions: **who judges** (does the edit move decisions toward the model's own discretion or toward an outside authority?) and **who benefits** (when an edit puts a cost on one party for another's benefit, who is the principal that benefits?). The reported numbers come from three blinded LLM graders combined by majority vote.

- Website (browse every edit and its coding): https://peterkirgis.github.io/llm-value-reflection/
- Write-up (LessWrong): https://www.lesswrong.com/posts/c9woewdY9ddsPqf3J
- Authors: Peter Kirgis and Tim Hua

## Quick start

    uv sync          # creates .venv/ with Python 3.12 and every dependency, pytest included
    make test        # the full test suite: offline, about 30 seconds
    make check       # raw-data checksums, majority-vote and website rebuild checks, README paths
    make figures     # redraw analysis/figures/ (reproduces the committed files byte for byte)
    make site        # rebuild docs/ from the consensus codes
    python3 -m http.server 8080 --directory docs     # preview the site at http://localhost:8080

None of these calls an API. `make site` changes only the `generated_at`
timestamps in `docs/data/site.json.gz` and
`analysis/data/analysis/site/selfcheck.json`; discard them with
`git checkout -- docs analysis/data/analysis/site` unless you meant to change
the site. A trial build with `build_site.py --out-dir <dir>` leaves the tree
untouched. `make documents` is needed only for stages 1, 2 and 4. The tests
that check git-history references skip themselves in a shallow clone; run
them in a full clone.

To call the APIs, put `OPENROUTER_API_KEY=...` in `.env` (gitignored). Run
`make cache` first: it unpacks the grader cache (its format is described in
[analysis/README.md](analysis/README.md), Data layout), and every grading
request is looked up there before the API is called. The API targets refuse
to run without `CONFIRM=1` and write only into `scratch/`: `make api-run`
writes new runs to `scratch/runs/`, and `make api-grade` re-grades every edit
into `scratch/grades/`, answered from the cache wherever a request is cached.

## Raw data

These files cannot be regenerated, or only at real cost. `raw_data.sha256`
lists all 58 with their checksums; `make check` (or
`shasum -a 256 -c raw_data.sha256`) verifies them. No `make` target writes to
them, and the scripts that could (`run.py`, `reconstruct_results.py`,
`qualitative_code.py`, `build_phase0.py`, `derive_no_csam.py`) write
elsewhere by default or refuse. Two scripts still append to raw files when
run directly: `analysis/src/grade.py` without `--out` appends to
`analysis/data/codes/v2_<grader>.jsonl`, and `analysis/src/e_runs.py`
appends to the `e*.jsonl` files. Both resume, so on the committed, complete
files they append nothing; anything they did append would show up as a
checksum failure.
